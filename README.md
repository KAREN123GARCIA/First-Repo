# 🐱‍🏍 **My First Repository**  

👋 **Welcome to my "hola" repository!**

This repository was created as part of the **Distributed Programming** course practice. In this project, I learned and experimented with version control using **Git** and **GitHub**. We followed the steps of creating a branch, committing changes, and managing files. Here's a breakdown of the tasks performed:

### 🛠️ **Tasks completed in this repository**:
1. **Create a new branch**: We created a new branch to work on our changes without affecting the main code.
2. **Created and deleted a `hello.py` file**: Initially, we created a Python file called `hello.py` and later deleted it to practice Git commands.
3. **Switched to the `test` branch**: After deleting the file, we created a new branch called `test` to work on new tasks.
4. **Added `hello.js` and `README.md` files**: In the `test` branch, we added a new JavaScript file (`hello.js`) and a README file to document the project.
5. **Deleted unnecessary files**: We practiced deleting files like `hello.py` and committing those changes to Git.

### 📌 **Key Learnings**:
- How to **create and switch branches** using Git.
- **Committing changes** and writing clear commit messages using the **Conventional Commits** format.
- **Pushing changes to GitHub** and making the repository public.
- Using **GitHub Pages** to host a personal webpage and showcase the project.

### 📦 **Technologies & Versions Used**:
- **Git**: Version 2.x
- **Node.js**: Version 14.x (used in the `hello.js` file for experimenting with JavaScript)
- **GitHub Pages**: To deploy the project and view it online.
- **Python**: Version 3.x (used for the initial `hello.py` file before it was deleted)

### 📝 **Commit Examples**:
Throughout this repository, I used **Conventional Commits** with emoticons to make the commit history more readable:

- `✨ feat: add hello.js file`
- `🐛 fix: delete hello.py file`
- `📝 docs: update README.md with project info`
- `🔧 chore: clean up test branch`
